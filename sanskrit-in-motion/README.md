# Sanskrit in Motion — Chapter 1, 3D Story Map

An interactive 3D globe story made from the places and literary journeys discussed in Sheldon Pollock’s Chapter 1, “Sanskrit Literary Culture from the Inside Out,” in *Literary Cultures in History*.

## Open the project

The project is a small static website. It needs an internet connection for the globe library and Earth imagery. After publishing to GitHub Pages, open the site URL. For a local preview, serve this folder over HTTP (opening `index.html` directly as a file does not allow the browser to load `data.json`).

## Follow the story

Choose one of eleven journeys from the menu. Use **Next stop** or the numbered stop list to move in the order described by the chapter. Click a point on the globe to open that stop. Drag to rotate the globe; use **Whole map** to return to an India-centered view. Each stop includes its chapter page reference.

## Source discipline and map notes

The story text, mapped location names, itinerary order, and chapter page references come from Chapter 1 only. The globe focuses on the literary routes and location groups discussed there rather than every incidental place name in the full chapter. Modern coordinates are orientation points added to place the text on a globe. Regional places use representative coordinates; uncertain and mythic locations are flagged. Routes depict a literary itinerary or reported connection, not a surveyed travel road. The map adds a visual comparison of the chapter’s different forms of literary geography; it does not add new historical evidence.

Basemap image and 3D globe rendering use [globe.gl](https://globe.gl/) and its [Three.js example assets](https://github.com/vasturiano/three-globe/tree/master/example/img). Their online delivery is subject to the providers’ terms.
